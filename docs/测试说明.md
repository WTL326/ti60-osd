# 指令构成

FPGA 侧所有命令统一使用包头 `BB`，机芯指令仍用 `AA`。一条 FPGA 命令帧如下：

```text
BB | len_hi | len_lo | dalei | zixiang | type | payload | crc_hi | crc_lo | AA
```

- `BB`：FPGA 命令统一包头（机芯是 `AA`）
- `len`：body 长度，`len = 3 + payload 字节数`，大端
- `dalei`：功能大类。`0x00` 掩膜，`0x01` 电子变倍
- `zixiang`：大类下的子项
- `type`：`0x00` 上位机写
- `payload`：子项参数，多字节字段均为大端
- `crc`：CRC-16/CCITT，初值 `0x0000`、多项式 `0x1021`，只对
  `dalei | zixiang | type | payload` 计算
- `AA`：帧尾，与机芯一致

应答固定 10 字节：

```text
BB | 00 04 | dalei | zixiang | 02 | status | crc_hi | crc_lo | AA
```

`status`：`0xFF` 成功，`0x00` 失败。

# 掩膜指令（dalei 0x00）
常用命令示例：
**设置掩膜位置**
```python 
python "./tools/send_mask_via_adb.py" --image ".\mask.bmp" --x 150 --y 178 --persist
python "./tools/send_mask_via_adb.py" --image ".\mask.bmp" --x 150 --y 100 
python "./tools/send_mask_via_adb.py" --disable
```
**负坐标，测试左上边界裁剪**
```python
python "./tools/send_mask_via_adb.py" --position-only --x=-100 --y=-50
```

**指定另一张420×220、24位BMP**
```python
python "./tools/send_mask_via_adb.py" --image ".\mask2.bmp" --x 50 --y 50
```
**调整二值化阈值**
```python
python "./tools/send_mask_via_adb.py" --threshold 200
```
**调整每包大小**
```python
python "./tools/send_mask_via_adb.py" --chunk 2048
```
```python
--x、--y：掩膜左上角坐标。
--image：掩膜BMP路径。
--threshold：白色判定阈值，默认240。
--chunk：分包大小，默认4096。
--device：X2000串口，默认 /dev/ttyS1。
--adb：指定 adb.exe 路径。
```

掩膜子项（dalei `0x00`）：

| zixiang | 名称 | payload（大端） |
|---|---|---|
| `0x01` | 开始上传 | `width:u16 height:u16 total:u32` |
| `0x02` | 分块写入 | `offset:u32 + bytes[]` |
| `0x03` | 设置位置 | `left_x:s16 top_y:s16` |
| `0x04` | 开关 | `enable:u8` |
| `0x05` | 保存 Flash | 无 payload |

# 电子变倍（dalei 0x01）
```python
python "./tools/send_zoom_via_adb.py"  --center --x 640 --y 512 --half-width 320 --half-height 256
python "./tools/send_zoom_via_adb.py" --corners --x0 100 --y0 80 --x1 1179 --y1 943
python "./tools/send_zoom_via_adb.py" --disable
```

电子变倍子项（dalei `0x01`）：

| zixiang | 名称 | payload（大端） |
|---|---|---|
| `0x01` | 设置 ROI | `x_left:u16 y_top:u16 x_right:u16 y_bottom:u16` |

- `--center`：中心 + 半宽/半高，脚本会自动换算成角点
- `--corners`：直接给左上角和右下角（含端点）
- `--disable`：发送全幅 `(0,0)-(1279,1023)`，即恢复 1 倍
- 没有独立的 `--enable`，发送 ROI 本身就是变倍命令


**上面这一组（显示/隐藏/按键/状态/标记/清除）在固件里只解析、不应答**，命令发出去不会回包，
`send_ui_via_adb.py` 会因超时抛错 —— 这是设计，不是故障。**要显示/隐藏菜单请用下面的 `--view`。**

真正会应答、会改变画面的三条路径：

```python
python "./tools/send_ui_via_adb.py" --view image --selected 0 --edit   # SET_VIEW 0x06：切页/选中/编辑态
python "./tools/send_ui_via_adb.py" --view image --hidden              # 隐藏菜单（flags.bit0=0）
python "./tools/send_ui_via_adb.py" --image-values 3 5 7 5             # SET_IMAGE_VALUES 0x07
python "./tools/send_ui_via_adb.py" --query-view                       # QUERY_VIEW 0x08：18 字节回读
```

- 固件只实现了 3 个菜单页（`0x0000` / `0x0100` / `0x0200`），其余页返回 `status=0x00`；
- 完整的命令清单、回包判据、画面判据与故障归因见
  [osd_menu_test_commands.md](osd_menu_test_commands.md)；
- 自动化验收：`python tools/check_ui_end_to_end.py`（先 `--dry-run` 可离机自检）。
